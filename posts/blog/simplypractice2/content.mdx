## 1. 오디오 장비의 연결
### -개요
&nbsp;먼저 오디오 장비를 연결해보고자 합니다. 기본적으로 기타 or 베이스 연주자들을 위한 연습 플랫폼이기 때문에 오디오 인터페이스와 같은 장비가 사용자의 시스템 오디오 아웃풋까지의 연결이 필요했습니다.

이전 게시물에서 ==AudioContext==와 ==AudioNode==에 대해 간략한 설명을 했었는데, 이번에 구현하는 기능들에도 두가지 모두가 사용되었습니다. 

### -연결 구조 설계
&nbsp;오디오 인풋 장비연결을 위해 설계한 연결구조는 다음과 같습니다.
`[MediaStreamAudioSourceNode] → [ChannelSplitterNode] → [GainNode] → [ChannelMergerNode] → [destination]`

각각의 노드는
- `MediaStreamAudioSourceNode`: 사용자 오디오 장비에서 들어오는 실시간 오디오 신호를 ==Web Audio API==에 연결하는 역할
- `ChannelSplitterNode`: 오디오 신호를 채널 단위로 나누어주는 역할(오디오 장치에서 선택된 채널을 다음 노드로 연결하기 위함)
- `GainNode`: ==AudioContext==내부에서 앞서 연결된 신호의 볼륨을 제어하는 역할
- `ChannelMerger`: 여러갈래의 신호를 하나로 합쳐주는 역할 (앞서 두 갈래로 나누어진 오디오 신호를 양쪽의 스테레오 장비에 출력하기 위함)
- `destination`: 최종 사용자 출력 장치로의 연결

과 같은 역할을 합니다.

최초 기획 단계에서는 ==eq==, ==reverb==와 같은 이펙팅을 추가하려고 했으나, 너무 많은 노드는 ==레이턴시==를 발생시키고, 이는 실시간 모니터링에 영향이 있기 때문에 최대한 단순한 구조의 연결을 구현했습니다.

### -데이터의 전역 관리
&nbsp;또한 선택된 오디오 장비, 장비의 ID, 장비 내부의 입력 채널, 갯수, 볼륨 등은 다양한 컴포넌트에서 활용 예정이라 ==zustand==스토어에 저장하였고, 서비스를 다시 이용할 때, 선택했던 장비를 다시 번거롭게 연결할 필요가 없게끔 ==persist==라는 미들웨어를 통해 저장하였습니다.

## 2. 구현
### -오디오 장비 불러오기
&nbsp;오디오 장비를 ==AudioContext==에 연결하기 위해서는 먼저 현재 브라우저에 사용가능한 오디오 장비 목록이 먼저 필요합니다. 오디오 장비 목록을 위해서 먼저 브라우저에서 오디오 장비 접근 권한을 확보합니다.
```ts
await navigator.mediaDevices.getUserMedia({ audio: true });
```
이렇게 권한을 요구하면

브라우저에서 상기와 같은 권한을 요청하게 되고, 사용자의 선택에 따라 장치에 대한 접근 여부가 결정됩니다. 

권한이 확보 된 후에는 

```ts
const devices = await navigator.mediaDevices.enumerateDevices();
const inputs = devices.filter((device) => device.kind === "audioinput");
```
와 같은 코드를 사용하여, 브라우저에 연결되어있는 미디어 장치들을 모두 열거한 후, 열거된 장치들의 `kind` 속성을 이용하여 오디오 입력장치만 필터링하면 됩니다.

이후에는 장치 목록과 기존의 ==zustand==스토어에 저장되어 있는 값을 대조하여, 기존 값이 없을 경우 장치의 `deviceId`속성을 이용하여 default값을 찾아낸 뒤, 저장해 주는 방식으로 구현하였습니다.
> utils/audioConnectionUtils.ts/getDevices
```ts
export async function getDevices(
  setDevices: (devices: MediaDeviceInfo[]) => void,
  setInputId: (id: string | null) => void,
  currentInputId: string | null
) {
  await navigator.mediaDevices.getUserMedia({ audio: true }); // 장치 사용 권한 요구

  const devices = await navigator.mediaDevices.enumerateDevices();
  const inputs = devices.filter((device) => device.kind === "audioinput");
  setDevices(inputs);

  const valid = inputs.some((device) => device.deviceId === currentInputId);

  if (valid && currentInputId) {
    setInputId(currentInputId);
  } else if (inputs.length > 0) {
    const defaultDevice = devices.find(
      (device) => device.deviceId === "default"
    ); // 디폴트 장비 연결
    if (defaultDevice) setInputId(defaultDevice.deviceId);
    else if (inputs.length > 0) setInputId(inputs[0].deviceId);
  } else {
    setInputId(null);
  }
}

```
### -오디오 장비 연결하기
&nbsp;이제 우리는 오디오 장치들의 목록과, 선택된 장비가 있습니다. 이제 이들을 토대로 오디오 입력 장비를 ==AudioContext==를 통해 오디오 출력 장비로 연결해보겠습니다.

먼저 해당함수는 연결하고자 하는 장치의 id(deviceId), 장치의 선택된 채널(channel), 볼륨(volume), AudioContext, MediaStream, GainNode, 채널 갯수 setter를 파라미터로 받습니다. 

먼저 파라미터 값들을 기준으로 오디오 연결을 전처리 합니다. 해당 과정에서 `MediaStream`과 `AudioContext`객체의 연결들을 제거하고, `AudioContext`의 상태에 따라 새로운 객체를 생성하거나, `resume`해줍니다.

> utils/audioConnectionUtils.ts/connectAudio
```ts
export async function connectAudio({
  deviceId,
  channel,
  volume,
  audioCtxRef,
  streamRef,
  gainRef,
  setChannelCount,
}: ConnectAudioParams) {
  // 오디오 생성 및 연결

  cleanAudioConnection(audioCtxRef, streamRef);

  let ctx = audioCtxRef.current;

  if (!ctx || ctx.state === "closed") {
    ctx = new AudioContext({ latencyHint: "interactive", sampleRate: 48000 });
    audioCtxRef.current = ctx;
  }

  // suspended 상태일 경우 resume
  if (ctx.state === "suspended") {
    await ctx.resume();
  }
```

이후 전처리가 끝나면, 파라미터로 들어온 ==deviceId==를 이용하여 ==MediaStream==을 생성하고, 이를 이용하여 ==MediaStreamAudioSourceNode==를 생성해줍니다.
> utils/audioConnectionUtils.ts/connectAudio
```ts
  const stream = await navigator.mediaDevices.getUserMedia({
    audio: {
      deviceId: { exact: deviceId },
      echoCancellation: false,
      autoGainControl: false,
      noiseSuppression: false,
    },
  });

  streamRef.current = stream;
  const source = ctx.createMediaStreamSource(stream);
```
여기서의 `MediaStream`은 입력장치에서 생성되는 실시간 데이터 스트림 객체입니다. 앞서 연결 구조 설계에서 언급한 `MediaStreamAudioSourceNode`는 해당 객체를 기반으로 생성되어, ==AudioContext==에 연결 가능한 상태로 생성이 가능합니다.

이후에는
> utils/audioConnectionUtils.ts/connectAudio
```ts
  const gainNode = ctx.createGain();
  const splitter = ctx.createChannelSplitter();
  const merger = ctx.createChannelMerger(2);

  gainNode.gain.value = volume;
```
와 같이 앞서 연결 구조 설계에서 언급한 각각의 노드들을 만들어줍니다. 여기서 `ChannelMergerNode`의 파라미터에 들어가는 숫자는 합치고자 하는 채널 수를 넣습니다.

마지막으로 
> utils/audioConnectionUtils.ts/connectAudio
```ts
  source.connect(splitter);

  splitter.connect(gainNode, channel);

  gainNode.connect(merger, 0, 0);
  gainNode.connect(merger, 0, 1);
  merger.connect(ctx.destination);
```
설계와 같이 `[MediaStreamAudioSourceNode] → [ChannelSplitterNode] → [GainNode] → [ChannelMergerNode] → [destination]`의 구조로 연결해주면 오디오 입력 장치(예: 오디오 인터페이스)로부터 들어온 신호가 브라우저를 거쳐 곧바로 출력 장치(스피커, 헤드폰 등)로 전달됩니다.

`ChannelSplitterNode`는 입력 장치의 모든 채널을 분리하는 역할을 하며,그중 사용자가 선택한 채널(즉, 실제 신호가 들어오는 채널)만 다음 노드(`GainNode`)로 전달합니다.

`GainNode`에서는 해당 채널의 볼륨이나 신호 세기 조절이 가능하며, 이 노드의 출력을 `ChannelMergerNode`의 좌우 출력 채널(0, 1)에 모두 연결함으로써, 단일 모노 입력을 스테레오 환경에서 양쪽으로 균등하게 출력되도록 합니다.

## 1. 언어모드를 만들어보자
### -개요
&nbsp;여러 프로젝트를 진행하면서 다크모드, 검색 기능 등 많은 웹 서비스에서 채택하는 기능들을 구현해보았지만, 언어모드는 개발 경험이 없기도 하고 흥미도 있어 이번 프로젝트에 언어모드를 추가하고자 했습니다.

### -선택지
&nbsp;언어모드를 구현하기 위해 처음에는 몇 가지 대표적인 라이브러리들을 검토했습니다.
- ==i18next== : 다국어 지원 프로젝트에서 가장 보편적으로 쓰이는 라이브러리
- ==react-intl== : 메세지 포맷, 날짜 등 국제화 세부 기능 지원
- ==react-i18next== : ==i18next==를 ==React==에 최적화한 버전. 훅 기반 문법 지원

하지만 이번 프로젝트는 규모가 크지않고, 프로젝트 특성 상 UI구조가 단순한 형태를 추구하였기 때문에, 굳이 복잡한 국제화 구조를 적용할 필요가 없다고 판단되었습니다.

또한 대부분의 텍스트가 고정된 컴포넌트 내부에 존재했고, 런타임 중 언어 전환이 실시간으로 이루어지는 단순 토글 형태였기 때문에 전역상태 관리(==zustand==)와 객체 매핑 방식을 사용하는 것이 더 낫다고 판단되었습니다.
개인적인 욕심으로 간단한 언어 기능을 직접 개발해보고 구조를 이해하고 싶은 마음도 존재했습니다.

따라서 언어별 텍스트를 직접 정의한 객체형태로 관리하고, 이를 전역 상태를 통해 현재 언어를 제어하는 구조로 개발 방향을 잡았습니다.

## 2. 개발
### -zustand 스토어
&nbsp;직접 언어모드를 개발하는 것은 다소 수고스럽지만 매우 간단한 작업입니다. 먼저, ==zustand== 스토어를 세팅해줍니다.

> src/stores/languageSettingStore.ts
```ts
import { create } from "zustand";
import type { LanguageStoreState } from "@/types/store/LanguageStoreState";
import { persist } from "zustand/middleware";

export const useLanguageStore = create<LanguageStoreState>()(
  persist(
    (set) => ({
      lang: "kor",
      initialized: false,
      setLang: (lang) => set({ lang }),
      setInitialized: () => set({ initialized: true }),
    }),
    {
      name: "language-storage",
    }
  )
);
```
한번 설정한 언어는 사용자가 웹서비스에 재방문을 해도 그대로 유지되게끔 `persist`를 사용하여 로컬 스토리지에 저장해줍니다. `setInitialized`는 후술할 최초 방문시에 사용합니다.

이후 언어 파일을 만들어줍니다.

### -커스텀 훅
&nbsp;언어 설정 기능에 추가 하고 싶은 마지막 기능은 브라우저 언어 추적 기능입니다.

지금 구조 상태로는 ==zustand== 스토어에 기본값으로 저장되어있는 한국어가 모든 사용자에게 일괄적으로 서비스 최초 방문 시에 세팅되게 됩니다. 이는 다른 언어권 사용자에게는 불편으로 다가올 수 있기 때문에, 서비스 최초 방문 시 브라우저의 언어를 추적하여 그에 맞는 언어가 잇다면 이를 스토어에 저장하고자 했습니다.

이를 구현하기 위해서 커스텀 훅 하나를 작성합니다.

>src/hooks/common/useBrowserLanguage.ts
```ts
import { useLanguageStore } from "@/stores/languageSettingStore";
import { useEffect } from "react";

export function useBrowserLanguage() {
  const { setLang, initialized, setInitialized } = useLanguageStore();

  useEffect(() => {
    if (initialized) return;
    const browserLang = navigator.language.toLowerCase();

    if (browserLang.startsWith("ko")) {
      setLang("kor");
    } else if (browserLang.startsWith("ja")) {
      setLang("jpn");
    } else {
      setLang("eng");
    }
    setInitialized();
  }, [setLang]);
}
```

먼저, `navigator.language` 속성에 접근하여 현재 브라우저의 언어를 반환받습니다. 이후 반환값을 점검하여 조건문에 따라 지원하는 언어가 있다면 해당 언어로, 없다면 영어로 언어를 세팅합니다.
앞서 스토어에 있었던 `setInitialized`는 여기서 사용합니다. 해당 브라우저가 웹서비스에 처음 방문하여 언어 세팅이 초기화 되었는지를 알수 있게하는 플래그입니다.
이후 해당 훅을 원하는 곳에 위치시키고, UI와 연계하면 자연스럽게 언어 모드 개발을 완료 할 수 있습니다.
